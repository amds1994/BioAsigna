Agente bioinspirado para repartir solicitudes de forma equilibrada

Un algoritmo genético propone qué funcionario atiende cada solicitud, respeta competencias y capacidad, y vuelve a optimizar cuando cambia el entorno.

Datos ficticios. Todos los escenarios son sintéticos. El sistema solo recomienda: una persona decide.

¿Qué sistema biológico imita?

La evolución por selección natural. Una población de repartos candidatos compite: los de menor costo J se seleccionan por torneo, se cruzan (intercambian segmentos) y mutan (cambian de responsable una solicitud). Los dos mejores se conservan (elitismo).

Límites de la analogía: es un algoritmo genético, no una red neuronal ni aprendizaje por refuerzo. Volver a optimizar tras un cambio no es aprendizaje continuo.
